  2. Venu X1 anschließen

    Die Uhr mit einem USB-Datenkabel an deinen Windows-PC anschließen. Ein reines Ladekabel reicht nicht. Falls die Uhr eine Verbindungsart abfragt, die Dateiübertragung wählen.

    Im Explorer unter „Dieser PC“ die Garmin-Uhr und gegebenenfalls „Internal Storage“ öffnen. Die PRG-Datei in GARMIN/APPS kopieren. Nicht den Quellcode und nicht die ZIP-Datei kopieren.

    Übertragung abschließen, Uhr sicher trennen und am Zifferblatt den Bearbeitungsmodus öffnen: je nach Softwarestand lange auf das Zifferblatt drücken oder das Zifferblatt-Menü verwenden. Das neue „Jorge“-Design auswählen und anwenden.

Noch keine PRG-Dateien? So entstehen die vier Builds +

Diese Schritte benötigen einen Computer. Der aktuelle Garmin-Quellcode ist noch nicht kompiliert und nicht auf der Venu X1 getestet.

  1. Java, Python 3.9+ und den offiziellen Garmin SDK Manager installieren.
  2. Im SDK Manager ein aktuelles SDK und das Geräteprofil „Venu X1“ installieren. Dazu kann eine Garmin-Anmeldung nötig sein.
  3. Visual Studio Code mit der Erweiterung „Monkey C“ installieren. Über „Monkey C: Generate a Developer Key“ einen privaten Entwicklerschlüssel erzeugen. Den Schlüssel nur lokal speichern.
  4. Den Projekt-Quellcode herunterladen, entpacken und ein Terminal im entpackten Projektordner öffnen.
  5. Das folgende Build-Skript mit den tatsächlichen SDK- und Schlüsselpfaden ausführen:
python tools/build.py --sdk "C:\Garmin\connectiq-sdk" --key "C:\Garmin\developer_key.der"

Windows-Beispiel: Pfade anpassen. Auf macOS/Linux ebenfalls python3 bzw. die passende Python-Installation und die dortigen SDK-Pfade verwenden. Die Dateien landen nach erfolgreicher Kompilierung im Ordner build. Danach zuerst im Simulator und auf der echten Venu X1 testen.

Optional: --alarm 06:30 ergänzt eine manuelle Weckzeitanzeige. Der eigentliche Wecker muss zusätzlich auf der Uhr gestellt werden.

HÄUFIGE FRAGEN

Gut vorbereitet.

Warum gibt es noch keinen Installieren-Button?

Der Garmin-Quellcode muss zuerst mit dem SDK kompiliert werden. Diese Seite prüft GitHub-Releases auf echte PRG-Dateien. Ein Download wird erst bei einem passenden Release-Asset freigeschaltet; das belegt noch keinen erfolgreichen Uhrentest.

Warum zeigt die Uhr keine Temperatur?

Die Anzeige verwendet Garmins zuletzt bereitgestellte Wetterdaten. Garmin Connect und die Uhr synchronisieren und prüfen, ob die native Wetteransicht Daten zeigt. Fehlende oder erkennbar mehr als zwei Stunden alte Wetterdaten erscheinen als Striche.

Wie ändere ich die manuelle Weckzeit?

Beim aktuellen Sideload-Build über --alarm HH:MM im Build-Befehl. Danach erneut bauen und übertragen. Connect-IQ-Einstellungen sind für eine spätere Store-Version vorbereitet. Dies stellt keinen Wecker.

Wie entferne oder aktualisiere ich ein Design?

Ein anderes Zifferblatt aktivieren und das Jorge-Zifferblatt über die Uhrenverwaltung entfernen. Für ein Update die neu gebaute PRG-Datei derselben Variante erneut übertragen. Den gleichen privaten Entwicklerschlüssel beim Bauen weiterverwenden.

Sind die Vorschauen echte Daten meiner Uhr?

Nein. Die Vorschau zeigt 78 % Akku, 16 °C, 8,42 km und 06:30 als Beispieldaten. Nur die eingeschaltete Live-Uhrzeit und das Datum kommen vom Browser. Es gibt keine Verbindung zu deinen Gesundheitsdaten.
