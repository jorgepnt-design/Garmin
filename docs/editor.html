Auf die Venu X1

Der Browser kann keine Garmin-PRG kompilieren. Mit der Designdatei und unserem Bauwerkzeug entstehen echte PRGs auf deinem Laptop.

  1. Aktuellen Projektordner herunterladen und entpacken.
  2. Garmin Connect IQ SDK, Geräteprofil Venu X1, Python mit Pillow und deinen privaten Entwicklerschlüssel bereitstellen.
  3. Designdatei als mein-design.json im Projektordner speichern. Im Terminal ausführen:
python -m pip install Pillow
python tools/build_custom.py mein-design.json --sdk "C:\Garmin\connectiq-sdk" --key "C:\Garmin\developer_key.der"

SDK- und Schlüsselpfad anpassen. Die Datei build/custom/Jorge-custom.prg zuerst im Garmin-Simulator prüfen und anschließend nach GARMIN/APPS auf die Uhr kopieren. Den Schlüssel privat halten.

Unterstützt werden die hier angebotenen Felder, Schriften, Symbole und eingebetteten Bilder. Der Alarm zeigt Anzahl und Status, keine nächste Weckzeit. Eigene Designs haben noch keine Verknüpfungen zu Garmin-Ansichten.
